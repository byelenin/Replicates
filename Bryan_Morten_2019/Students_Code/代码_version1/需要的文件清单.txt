【二】Stata 外部命令
--------------------------------------------------------------------------------------------
必需（SSC 安装）：
    ssc install reghdfe, replace        （135 处调用，几乎所有回归）
    ssc install ppmlhdfe, replace       （10 处，PPML 路线）
    ssc install estout, replace         （1 处 esttab）
    ssc install gtools, replace         （reghdfe 依赖）
    ssc install moremata, replace       （reghdfe 依赖）
    ssc install require, replace        （reghdfe v6 依赖管理器）

Stata 自带、无需安装：
    ivpoisson / gmm / ivregress / areg / bootstrap / mata

尚未使用但后续可能需要：
    boottest —— 用于 wild cluster bootstrap 重算双向聚类星号
