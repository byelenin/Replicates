【三】重要：脚本里的路径是写死的
--------------------------------------------------------------------------------
  本包中的 .do 文件与原版【完全一致，一个字都没有改】。
  它们内部写死了上面第二节里那些绝对路径。

  ⇒ 在原电脑上：所有脚本都能直接跑（数据就在原来的位置）。
  ⇒ 换到别的电脑：需要改路径，或者把数据放回上述原始路径。

  还要特别注意：宏名 root 在不同脚本里含义不同 ——
      多数脚本        local root "D:\研一上\微观计量"
      11 个 t3_*.do   local root "C:\Users\任娜\Documents\deepseek-harness\default-workspace"
      fz              D:\研一上\微观计量\复现
      ussrc           ……\usa_od.csv 的完整路径（6 个脚本）
      work            工作区绝对路径（alpha_d_replication.do）
  ⇒ 不能批量替换，必须逐个脚本看它的 local 定义。

【四】Stata 外部命令（需自行安装）
--------------------------------------------------------------------------------
  ssc install reghdfe, replace        （135 处调用）
  ssc install ppmlhdfe, replace       （10 处）
  ssc install estout, replace         （1 处 esttab）
  ssc install gtools, replace         （reghdfe 依赖）
  ssc install moremata, replace       （reghdfe 依赖）
  ssc install require, replace        （reghdfe v6 依赖管理器）

  Stata 自带无需安装：ivpoisson / gmm / ivregress / areg / bootstrap / mata

  注意：00_环境与依赖\install_deps.do 只装后三个依赖，
        它假设 reghdfe 本体已经装好（脚本里只做 which reghdfe 检查）。
